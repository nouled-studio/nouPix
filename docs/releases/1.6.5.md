## What's new in 1.6.5

**Patch**

- **Patch each controller the way the device is set up.** Next to the protocol, **Patch mode** offers three ways (click the **i** for which fits your device):
  - **Unis:** a number of universes per output, each output starting where you type.
  - **Pix:** a number of pixels per output, and nouPix works out the universes. Each output starts right after the last one, on a new universe, or where you type.
  - **Man:** no outputs. One list of fixtures, each with its own universe and channel. Change one and the others stay put; two fixtures on the same channels are shown in red.
- Outputs can each have their own count, for devices whose ports differ.
- Adding a device from Discovery suggests a patch mode for it.
- **Universe numbers** (from 0 or from 1) are in **Output settings**, for devices that number universes from 1. What is sent doesn't change.
- Projects from before patch exactly as they did.

**Tunable white fixtures**

- New pixel types **WC** and **CW**: two channels a pixel, warm and cold white. The content's colour sets the mix: reds and oranges the warm, blues the cold, white and greys both. In the Inspector, **On white** (both full, or sharing one level) and **Balance** (warmer or colder), and a trim per channel.

**Import .mad files (beta)**

- **Project → Import .mad file (beta)…**, next to Import SVG (also on the stage's right-click and + Add): pick the `.mad` file inside a `.madproject` folder (made with MadMapper 6). Its rings, lines and matrices come in fitted to the canvas, with their pixel counts, pixel types, wiring and groups. With **Patch** ticked, each device in the file becomes a Manual controller with its address, and each fixture goes at its universe and channel. **Flip upside down** if it comes in upside down. A beta: check it against the original before a show.

**Updates**

- **Updates download inside the app:** when a new version is out, Download in the update window now fetches the installer into your Downloads folder without opening a web browser, with a progress bar. When it's there, **Install now** closes nouPix and installs the new version over it (on a Mac, **Open installer** opens the disk image: drag nouPix onto Applications). Your projects and settings stay. This works from this version on, for the updates that come after it.
