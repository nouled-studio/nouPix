## What's new in 1.3.1

**A calmer interface**
- Much less text in the panels. Where an explanation still helps, rest the mouse on a row's name to read it.
- **Settings** in six sections: Output, Pixels, Canvas, Scenes, Remote control, and This computer for what stays on this computer (the look, the startup project, the media library, updates).
- The bridge's address only shows when nouPix can't reach it.

**Zones and layers**
- A trash icon on each zone and layer removes it; Ctrl+Z brings it back.
- **Ctrl+D** duplicates the selected layer while the Content tab is open.
- The layer section keeps just Source, Blend and Opacity.

**Sources**
- A search box with an icon, and one list to show the sources for a use (Architectural, Ambient, Show, Utility) instead of four buttons.

**Smaller things**
- Scenes: **Default fade** and **Auto snapshot** in Settings; **Take snapshot**, **Retake snapshot** and **Remove snapshot** in a scene's menu.
- **Set universe and channel**, in a fixture's Output section, for the advanced patch.
- A new README with screenshots.
